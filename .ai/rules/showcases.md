# Showcases

## Counts that link to lists go in the subNavigation, not showcase cards
A count that opens a list (suppliers, products, deliveries…) belongs in the page head's subNavigation row (number + label + leftIcon + route), like the Accounting dashboard pills, never as stat cards at the top of a showcase. Raul, 22 Nov 2026: all views are to be homologated this way; the agent showcase cards were removed and Deliveries moved into WithAgentSubNavigation.

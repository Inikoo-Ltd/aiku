<aside class="tldr">
Your app is older than the oldest version Aiku still accepts. Install the update from the link on the screen, then open the app again.
</aside>

## What happened

Aiku has changed in a way that older versions of the app cannot follow, so it asks every phone below a minimum version to update first.

## What to do

1. Press **Update** and install the new version.
2. Open the app again and sign in if asked.
3. Actions waiting on the phone are kept through the update.

## When to ask a supervisor

If the update link does not work or the phone cannot install it.

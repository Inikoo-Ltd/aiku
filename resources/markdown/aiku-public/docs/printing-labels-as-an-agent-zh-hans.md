<aside class="tldr">
面向协调代理商。您为我们采购的货物,离开供应商时必须已经贴好标签。我们的合规团队为每个产品制作标签并发布;您需要连同货物的批次编号和有效期一起打印,并确保每一件货物上都贴上。您不能修改标签。如果标签上有错误,请告诉采购方。标签是如何制作的,见 <a href="/docs/making-compliance-labels">制作合规标签</a>。
</aside>

## 您的标签在哪里

在您的组织中,打开 **Procurement**（采购）→ **Labels**（标签）。**Labels to print**（待打印标签）页面列出您为我们采购的、已发布标签的每个产品,包含产品编码、名称,以及采购方公司。每个产品下面是它的标签。

您只能看到自己为我们采购的产品,并且只显示已发布的标签。仍在制作中的标签不会出现。

使用搜索框按产品编码或名称查找产品。

## 打印一张标签

1. 找到产品,按标签旁边的 **Print**（打印）。
2. 按照供应商标记的批次编号,原样填写货物的 **Batch code**（批次编号）。
3. 选择货物的 **Expiry date**（有效期）。没有有效期的标签不会要求填写。
4. 按 **Open PDF**（打开 PDF）。标签页会在新标签页中打开,每张标签上都印有您填写的批次编号和有效期。
5. 用标签纸按实际尺寸(100%)打印。不要使用"适应页面",那样会改变标签的尺寸。

**Open PDF**（打开 PDF）只有在批次编号和有效期都填写后才能使用。没有这两项,标签绝不会打印,因此一张标签纸上印的,始终是您面前这批货物的批次。

每个批次都要重新打印一张。标签上印错了别的批次的编号,比没有标签更糟。

## 产品还没有标签时

列表上方,页面会显示您为我们采购的产品中,有多少个还没有发布标签。您不能自己制作标签。请告诉采购方是哪个产品、货物什么时候准备好,以便在打包前发布标签。

## 良好习惯

- **打印其余标签前先核对第一张标签**与货物是否一致:产品、批次编号、有效期。
- **在交货前给每一件需要贴标签的货物贴上标签。**
- **发现标签有误,哪怕是很小的错误,也要报告给采购方。** 标签一旦修正,所有打印它的人看到的都会是修正后的版本。

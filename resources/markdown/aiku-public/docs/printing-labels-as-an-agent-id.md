<aside class="tldr">
Untuk agen koordinasi. Barang yang Anda beli untuk kami harus sudah berlabel saat meninggalkan pemasok. Tim kepatuhan kami membuat label untuk setiap produk dan mempublikasikannya; Anda mencetaknya dengan batch code dan expiry date barang dan memastikan label itu terpasang pada setiap unit. Anda tidak bisa mengubah sebuah label. Jika ada yang salah pada label, beri tahu buyer. Cara label dibuat dijelaskan di <a href="/docs/making-compliance-labels">making compliance labels</a>.
</aside>

## Di mana label Anda berada

Di organisasi Anda, buka **Procurement** → **Labels**. Halaman **Labels to print** mencantumkan setiap produk yang Anda beli untuk kami yang sudah memiliki label terpublikasi, lengkap dengan kodenya, namanya, dan perusahaan yang membelinya. Di bawah setiap produk ada label-labelnya.

Anda hanya melihat produk yang Anda beli untuk kami, dan hanya label yang sudah dipublikasikan. Label yang masih dibuat tidak akan muncul.

Gunakan kotak pencarian untuk menemukan produk berdasarkan kode atau namanya.

## Mencetak sebuah label

1. Temukan produknya dan tekan **Print** di sebelah labelnya.
2. Ketik **Batch code** barang, persis seperti yang ditandai pemasok pada batch tersebut.
3. Pilih **Expiry date** barang. Label yang tidak punya expiry date tidak akan memintanya.
4. Tekan **Open PDF**. Lembar label terbuka di tab baru, dengan batch code dan expiry date Anda pada setiap label.
5. Cetak di kertas label pada ukuran asli (100%). Jangan gunakan "fit to page", karena itu mengubah ukuran label.

**Open PDF** hanya berfungsi setelah batch code dan expiry date terisi. Label tidak akan pernah tercetak tanpa keduanya, sehingga satu lembar selalu memuat batch dari barang yang ada di depan Anda.

Cetak lembar baru untuk setiap batch. Label dengan batch code dari batch lain lebih buruk daripada tidak ada label sama sekali.

## Saat sebuah produk belum memiliki label

Di atas daftar, halaman ini memberi tahu berapa banyak produk yang Anda beli untuk kami yang belum memiliki label terpublikasi. Anda tidak bisa membuatnya sendiri. Beri tahu buyer produk mana itu dan kapan barangnya akan siap, agar labelnya terpublikasi sebelum barang dikemas.

## Kebiasaan baik

- **Periksa label pertama** terhadap barangnya sebelum mencetak sisanya: produk, batch code, expiry date.
- **Beri label pada setiap unit** yang memerlukannya sebelum barang diserahkan.
- **Laporkan kesalahan** pada label kepada buyer, sekecil apa pun. Label diperbaiki sekali untuk semua orang yang mencetaknya.

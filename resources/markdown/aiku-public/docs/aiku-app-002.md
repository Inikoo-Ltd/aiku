## What happened

Aiku received the request but failed while handling it (a server error). Your last action was not saved. The engineers are told about every error of this kind automatically.

## What to do

1. Wait a moment and press **Try again**.
2. If the same screen fails again, open **Menu → Report a problem**. The support reference (a long code of letters and numbers) is filled in for you, so the engineers can find what went wrong.
3. You can carry on with other work in the meantime.

## When to ask a supervisor

If the same action keeps failing and the work cannot wait, ask a supervisor to do it on the Aiku website.

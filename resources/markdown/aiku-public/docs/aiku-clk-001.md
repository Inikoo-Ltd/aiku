<aside class="tldr">
The QR code you scanned is not a valid clocking code for you right now. Read the message under it, scan the code on the clocking machine again, or use another clocking method.
</aside>

## What happened

Aiku checked the scanned code and refused it. It may not be a clocking machine's code, the code may have changed, or you are too far from the machine. The message on the screen comes from Aiku and says which.

## What to do

1. Scan the QR code shown on the clocking machine again.
2. If the message mentions your location, stand next to the machine and allow location access.
3. Use another clocking method your organisation allows (PIN or your employee code).

## When to ask a supervisor

If you cannot clock in at all: ask HR or your supervisor to record your time.

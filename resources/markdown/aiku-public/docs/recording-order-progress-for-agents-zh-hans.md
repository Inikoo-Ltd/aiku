<aside class="tldr">
面向协调代理商。采购方会按七个阶段跟踪每一张订单：已提交、定金已付、生产中、已就绪且质检通过、已发货、已到达并清关、已收货。它自己就能看到货物何时发出、何时送达，但看不到供应商那边发生了什么。这部分需要靠您来记录：在每张发给供应商的订单上，记录定金何时付清、生产何时开始、生产何时完成，您预计货物就绪的日期，以及您把货物交给货运代理的日期。每件事发生当天就记录。采购方视角见 <a href="/docs/reading-the-po-journey-board">reading the PO journey board</a>（英文）。
</aside>

## 您的日期为什么重要

采购方通过您下达的每一张订单，其阶段都会显示在订单页面顶部，也会在 <b>PO journey</b> 看板上显示为一行。每个阶段都会显示日期和记录人。阶段一旦超过目标日期，就会在看板上变红，并显示已经延误了多少天。

如果没有您记录的日期，采购方在您这一端只能看到两件事：订单发给您的那天，以及货物离开的那天。中间发生的一切都是不可见的，不管延误发生在供应商那里、质检环节还是交接环节，看起来都一样。有了您的日期，各阶段就能准确显示订单走到了哪一步，供应商的延误在货物本该发运的几周之前就能被看到。

您在一张订单上记录了第一个日期之后，后续的日期就在预期之中。如果某个阶段的目标日期已过，而您还没有记录，该阶段就会显示为延误，即使工作实际上已经完成。缺失的日期，看起来和真正的延误一模一样。

## 您需要记录的日期

| 日期 | 记录时机 | 位置 |
|---|---|---|
| Deposit paid（定金已付） | 供应商收到定金时。 | 订单付款面板中的 **Pay deposit**，填写金额并附上银行对账单。记录的第一笔付款即为定金，之后的付款为尾款。 |
| Production started（生产开始） | 供应商开始生产货物时。 | 订单顶部各阶段上的 **Production started** 按钮。 |
| Production done（生产完成） | 供应商完成货物生产时。“完成”指整张订单全部完成，而非第一批。 | 订单顶部各阶段上的 **Production done** 按钮。 |
| Proposed ready date（建议就绪日期） | 您知道货物何时能够准备好交接时。这是您认为可信的日期，采购方会核准它。 | 订单 **Edit** 页面的 **Clean handover**（干净交接）部分。 |
| Handed over（已交接） | 货物送到货运代理手中时。指整张订单全部送到，而非第一部分。 | 订单顶部各阶段上的 **Handed over** 按钮。 |
| Your order number（您的订单号） | 您有自己的订单编号时。 | 订单 **Edit** 页面的 **Agent's order number**。它显示在 PO submitted 下方。 |

各阶段按顺序进行。每个日期都要在发生当天记录。如果日期早于今天超过一天、记录的阶段先于它的前一阶段，或者您清除了某个日期，系统会要求您填写原因。原因连同您的姓名一起保存在订单历史中，采购方可以看到。

## 采购方记录哪些内容

有些日期，按照设计，您本来就无法自己录入：

- **样品已核准（Sample approved）。** 由采购方核准样品。仅适用于新产品，返单没有样品环节。
- **核准就绪日期（Approved ready date）。** 采购方核准您提议的日期后，该日期即被锁定，并据此设定后续目标：质检须于当天完成，干净交接须在其后七天内完成。
- **质检通过（QC passed）。** 由采购方确认，通常依据您提供的质检证据。批准质检会放行尾款：在此之前支付尾款，系统会要求您填写原因。
- **合规文件包完整。**

您的 <a href="/docs/your-clean-handover-score-zh-hans">交接合格率（CHS）</a> 根据这些日期以及您记录的交接日期计算。交接日期由您来记录，所以请记录货物实际送到货运代理的那一天。采购方可以看到是谁、在何时记录的，可以对照货运代理的收货凭证核对，也可以更正；更正连同原因会保存在订单历史中。

## 供应商更改价格时

如果供应商在您确认订单之前要求新价格，请不要按旧价格确认。打开订单，在 <b>Items</b>（商品明细）中找到该产品，点击它那一行上的 <b>Supplier changed the price</b>（供应商已更改价格）。按显示的每箱单位填写供应商要求的价格，需要的话再写一条简短说明，然后点击 <b>Ask the organisation</b>（询问采购方）。

采购方会收到通知，并在该行上作答：接受新价格、保留旧价格，或设定另一个价格。您也会收到答复通知。订单上的每个价格问题都得到答复之前，<b>Confirm</b>（确认）按钮会保持灰色。如果采购方保留旧价格，而供应商不肯按这个价格出售，请在确认之前取消该行。

## 供应商更改数量时

如果供应商无法供应所订数量，或只按更大的批量销售，请在确认之前先询问采购方。打开订单，在 <b>Items</b>（商品明细）中找到该产品，点击其数量下方的 <b>Ask for another quantity</b>（请求其他数量）。按 Items 标签页显示的单位（箱、SKO 或件）填写数量，需要的话再写一条简短说明，然后点击 <b>Ask the organisation</b>（询问采购方）。

采购方会收到通知，并在该行上作答：接受新数量或保留旧数量。您也会收到答复通知。订单上的每个数量问题都得到答复之前，订单无法确认。

## 良好习惯

- **当天就记录。** 当天花五秒钟记录，能省去日后为一个变红的阶段争论的麻烦，也省去填写原因。
- **提出您真正相信的就绪日期。** 一个能兑现的现实日期，好过一个兑现不了的乐观日期。
- **日期可能延后时，尽早告诉采购方。** 及时商定的新核准日期能让订单保持在正轨上；没人同意就自行延后的日期，会显示为延误。

<aside class="wayfinder">
<b>需要的权限</b><br>
您所属代理商组织的登录账号。您只能在自己的订单上标记自己负责的阶段：阶段上的生产开始、生产完成和已交接、以付款形式记录的定金，以及在编辑页面填写的建议就绪日期和您的订单号。样品核准、核准就绪日期、QC 和合规相关项目不对您开放，因为这些由采购方记录。

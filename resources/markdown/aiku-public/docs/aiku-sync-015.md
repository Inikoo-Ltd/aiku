<aside class="tldr">
The delivery note, delivery or return had moved on (for example it was packed, dispatched or booked in) before your action reached Aiku, so the action was not recorded.
</aside>

## What happened

Someone moved the record on while you were offline. The conflict message names the stage it is in now.

## What to do

1. Read the message on the conflict and check the goods.
2. Put them back if needed and press **I put it back**, otherwise press **Done**.

## When to ask a supervisor

If the goods are already in a box or on a pallet that has left.

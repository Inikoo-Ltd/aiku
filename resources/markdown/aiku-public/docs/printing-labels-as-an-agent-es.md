<aside class="tldr">
Para agentes de coordinación. La mercancía que compras para nosotros debe salir del proveedor ya etiquetada. Nuestro equipo de cumplimiento normativo crea la etiqueta de cada producto y la publica; tú la imprimes con el código de lote y la fecha de caducidad de la mercancía y te aseguras de que va en cada unidad. No puedes cambiar una etiqueta. Si algo en ella está mal, avisa al comprador. Cómo se crean las etiquetas se explica en <a href="/docs/making-compliance-labels-es">crear etiquetas de cumplimiento normativo</a>.
</aside>

## Dónde están tus etiquetas

En tu organización, abre **Procurement** → **Labels**. La página **Labels to print** enumera cada producto que compras para nosotros que tiene una etiqueta publicada, con su código, su nombre y la empresa que lo compra. Debajo de cada producto están sus etiquetas.

Solo ves los productos que compras para nosotros, y solo las etiquetas que están publicadas. Una etiqueta que todavía se está creando no aparece.

Usa el buscador para encontrar un producto por su código o su nombre.

## Imprimir una etiqueta

1. Encuentra el producto y pulsa **Print** junto a su etiqueta.
2. Escribe el **Batch code** de la mercancía, exactamente como lo marca el proveedor en el lote.
3. Elige la **Expiry date** de la mercancía. Una etiqueta sin fecha de caducidad no la pide.
4. Pulsa **Open PDF**. La hoja de etiquetas se abre en una pestaña nueva, con tu código de lote y tu fecha de caducidad en cada etiqueta.
5. Imprímela en el papel de etiquetas a tamaño real (100%). No uses "ajustar a página", cambia el tamaño de las etiquetas.

**Open PDF** solo funciona cuando el código de lote y la fecha de caducidad están rellenados. La etiqueta nunca se imprime sin ellos, así que una hoja siempre lleva el lote de la mercancía que tienes delante.

Imprime una hoja nueva para cada lote. Una etiqueta con el código de lote de otro lote es peor que no tener etiqueta.

## Cuando un producto no tiene etiqueta

Encima de la lista, la página indica cuántos de los productos que compras para nosotros todavía no tienen una etiqueta publicada. No puedes crear una tú mismo. Dile al comprador de qué producto se trata y cuándo estará lista la mercancía, para que la etiqueta se publique antes de que se empaquete.

## Buenas costumbres

- **Comprueba la primera etiqueta** contra la mercancía antes de imprimir el resto: producto, código de lote, fecha de caducidad.
- **Etiqueta cada unidad** que lo necesite antes de entregar la mercancía.
- **Informa de los errores** en una etiqueta al comprador, incluso los pequeños. La etiqueta se corrige una vez para todos los que la imprimen.

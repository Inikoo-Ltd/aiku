</aside>

## What happened

The app tried to read the phone's location for the clocking check, but location access is refused or switched off.

## What to do

1. Open the phone settings and allow location access for Aiku.
2. Make sure location (GPS) is switched on for the phone.
3. Scan the clocking machine's QR code again.

## When to ask a supervisor

If location access is locked on a company phone.

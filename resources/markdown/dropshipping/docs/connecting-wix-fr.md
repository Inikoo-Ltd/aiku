<aside class="tldr">
Allez dans <b>Chaînes</b>, appuyez sur <b>Ajouter un canal de vente</b>, puis sur <b>Connecter</b> sur la carte Wix. Wix s'ouvre dans un nouvel onglet : choisissez votre site et installez notre application. Une fois l'installation terminée, Wix vous renvoie vers votre nouveau canal dans votre compte dropshipping. Votre site Wix doit avoir <b>Wix Stores</b> installé, sinon le canal reste non prêt.
</aside>

## Avant de commencer

- Vous avez besoin d'un site Wix avec <b>Wix Stores</b> installé. Nous ajoutons des produits à Wix Stores et y lisons vos commandes. Vous pouvez installer notre application sur un site sans Wix Stores, mais le canal reste non prêt tant que vous ne l'avez pas ajouté.
- Connectez-vous à Wix dans le même navigateur, avec le compte propriétaire du site.
- Wix est disponible sur tous nos sites de dropshipping. Connectez-le depuis le site où vous avez votre compte dropshipping.

## Connecter votre site Wix

1. Ouvrez <b>Chaînes</b> dans le menu. La page <b>Canaux de vente</b> liste les canaux que vous avez déjà.
2. Appuyez sur <b>Ajouter un canal de vente</b>. La page <b>Créer des chaînes</b> s'ouvre.
3. Trouvez la carte <b>Wix</b> et appuyez sur <b>Connecter</b>. Wix s'ouvre dans un nouvel onglet.
4. Si Wix vous le demande, connectez-vous. Choisissez le site que vous voulez connecter et installez l'application. Wix affiche les permissions dont l'application a besoin ; acceptez-les pour continuer.
5. Une fois l'installation terminée, Wix vous renvoie vers votre compte dropshipping et ouvre le tableau de bord de votre nouveau canal.

Terminez l'installation dans les deux heures suivant l'appui sur <b>Connecter</b>. Passé ce délai, le lien expire et vous devez appuyer à nouveau sur <b>Connecter</b>.

Le canal reprend le nom de votre site Wix. Vous pouvez le changer plus tard dans <b>Gérer le canal de vente</b>, <b>Store name</b>.

## Vérifier que le canal est prêt

Sur le tableau de bord du canal, à côté du nom du canal, vous voyez trois petites coches :

- <b>App installed</b> : nous pouvons joindre votre site Wix.
- <b>Exist in platform</b> : le site existe sur Wix.
- <b>Platform status</b> : le site est prêt à vendre nos produits.

Passez la souris sur une coche pour voir son nom. Trois coches vertes signifient que vous êtes prêt à ajouter des produits. Poursuivez avec le guide sur l'import de produits vers Wix.

Si nous ne pouvons pas du tout joindre votre site Wix, les coches ne s'affichent pas. Vous voyez à la place un message rouge, expliqué ci-dessous.

<!-- screenshot: le tableau de bord du canal avec le logo Wix, le nom du canal et trois coches vertes -->

Le tableau de bord affiche aussi des encadrés pour <b>Orders</b> et <b>Products</b>. Appuyez sur <b>Afficher tout</b> sur un encadré pour ouvrir cette liste.

## Connecter plusieurs sites Wix

Chaque site Wix est son propre canal. Pour ajouter un autre site, retournez sur <b>Chaînes</b>, appuyez sur <b>Ajouter un canal de vente</b> et sur <b>Connecter</b> sur la carte Wix à nouveau, puis choisissez l'autre site dans Wix.

## En cas de problème

<b>La page indique : Wix Stores is not installed on this site. Add the Wix Stores app to the site, then reconnect the channel.</b>
Votre site n'a pas de boutique en ligne. Dans Wix, ajoutez l'application Wix Stores au site. Puis ouvrez le canal dans votre compte dropshipping et appuyez sur <b>Essayez de vous reconnecter</b>.

<b>La page indique : Your channel is not connected yet to the platform.</b>
Nous n'avons pas pu joindre votre site Wix. Cela arrive quand l'application a été retirée du site, ou que l'installation ne s'est pas terminée. Appuyez sur <b>Essayez de vous reconnecter</b>. L'installateur Wix s'ouvre à nouveau : installez l'application sur le même site.

<b>L'onglet Wix affiche un court message au lieu de vous renvoyer</b>
- <b>The Wix installation was not completed</b> : l'installation a été interrompue avant la fin. Appuyez à nouveau sur <b>Connecter</b> et terminez toutes les étapes dans Wix.
- Une page d'erreur : le lien a plus de deux heures. Retournez sur <b>Créer des chaînes</b> et appuyez à nouveau sur <b>Connecter</b>.

<b>Vous voulez recommencer</b>
Sous l'avertissement du tableau de bord du canal, appuyez sur <b>Supprimer</b> à côté de <b>Or delete the channel and try again</b>. Puis reconnectez le site depuis <b>Créer des chaînes</b>.

Si vous avez retiré notre application de votre site Wix volontairement, le canal cesse de fonctionner : nous ne pouvons plus envoyer de stock ni recevoir de commandes. Réinstallez l'application avec <b>Essayez de vous reconnecter</b> pour réutiliser le canal.

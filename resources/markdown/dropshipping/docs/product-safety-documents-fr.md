Nous publions les FDS, IFRA, déclarations d'allergènes, CPSR, déclarations de conformité et rapports d'essai. Tout autre document n'est pas publié : demandez-le-nous via le chat de notre site.

## Où trouver les documents

1. Ouvrez la page du produit sur notre site.
2. Cliquez sur <b>Product Specifications & Documentations</b> pour l'ouvrir.
3. En bas du tableau, chaque type de document a sa propre ligne, avec les fichiers à télécharger. Cliquez sur un fichier pour l'ouvrir. Les fichiers PDF ont une icône rouge.

<!-- screenshot: la section Product Specifications & Documentations ouverte avec une ligne SDS et une ligne IFRA et leurs fichiers PDF -->

Le même tableau affiche aussi, quand nous les avons : <b>Origin</b>, <b>Net Weight</b>, <b>Shipping Weight</b>, <b>Dimensions</b>, <b>Materials/Ingredients</b> (parfois avec une étiquette à télécharger en PDF), <b>Barcode</b>, <b>cpnp</b> et <b>Origin Country</b>.

## Quels documents nous publions

Seuls ces types s'affichent sur la page produit :

- <b>SDS</b> : la fiche de données de sécurité.
- <b>IFRA</b> : le certificat IFRA pour les produits parfumés.
- <b>Allergen Declarations</b>.
- <b>CPSR</b> : le rapport de sécurité du produit cosmétique.
- <b>Declaration of Conformity</b>.
- <b>Test Reports</b>.

Tous les produits n'ont pas tous les documents. Une ligne ne s'affiche que lorsque nous avons ce document pour le produit. Si la section n'a aucune ligne de document, nous n'en avons publié aucun pour ce produit.

Les autres documents ne sont pas publiés sur le site, par exemple les étiquettes CLP ou les anciennes fiches MSDS. Si vous en avez besoin, ou qu'un document manque, contactez-nous via le chat de notre site et indiquez-nous le code produit et le document dont vous avez besoin.

## En cas de problème

**TikTok ou une autre place de marché demande un document de sécurité.** Téléchargez-le depuis la page produit et téléversez-le vous-même sur la place de marché. Si la place de marché demande un document que nous ne publions pas, contactez-nous via le chat de notre site.

**TikTok demande un numéro de lot.** Le numéro de lot n'est pas sur la page produit. Contactez-nous via le chat de notre site, avec le code produit.

**TikTok ou eBay a besoin du poids.** Utilisez le <b>Net Weight</b> ou le <b>Shipping Weight</b> dans le même tableau.

**Le document concerne un produit différent ou semble périmé.** Indiquez-nous le code produit et le nom du document via le chat de notre site, afin que nous puissions vérifier.

<aside class="tldr">
Vos commandes TikTok doivent utiliser un modèle d'expédition « Shipped by Seller ». Nous envoyons le colis avec nos transporteurs et le suivi remonte vers TikTok pour vous. Les commandes qui utilisent TikTok Shipping peuvent être annulées, alors configurez cela avant votre première vente.
</aside>

## Pourquoi c'est important

Chaque commande TikTok porte le type d'expédition de votre modèle.

- **Shipped by Seller** : nous préparons la commande, l'envoyons avec notre transporteur, et quand elle est expédiée nous envoyons le numéro de suivi à TikTok. La commande apparaît comme expédiée sur TikTok. Vous n'avez rien à faire.
- **TikTok Shipping** : collecte ou point relais propres à TikTok. Ne l'utilisez pas. Ces commandes peuvent être annulées.

## Créer le modèle

Les écrans ci-dessous se trouvent dans TikTok Shop Seller Center. TikTok peut changer leurs noms.

1. Ouvrez « Logistics » puis « Shipping ».
2. Appuyez sur « Add Template ».
3. Choisissez « Shipped by Seller » et appuyez sur « Continue ».
4. Remplissez le modèle :
   - « Template Name » : un nom que vous reconnaîtrez.
   - « Flat Rate » : les frais d'expédition payés par vos acheteurs. Vous pouvez fixer des frais différents selon le poids.
   - « New Region » : ajoutez-la si vous vendez vers des régions en dehors de votre région principale.
5. Appuyez sur « Submit ».

<!-- screenshot: TikTok Seller Center, fenêtre Add Template avec Shipped by Seller sélectionné -->

Les frais d'expédition de ce modèle sont ce que vos acheteurs vous paient. Cela ne change pas ce que nous vous facturons pour l'envoi de la commande.

## Lier le modèle à votre entrepôt

1. Dans la liste des modèles, trouvez votre nouveau modèle et cliquez sur le lien sous « Linked To ».
2. Sur la page de l'entrepôt, appuyez sur « Change Shipping Template » dans la colonne « Action ».
3. Choisissez votre nouveau modèle, pas celui par défaut, et appuyez sur « Save ».

<!-- screenshot: liste des entrepôts de TikTok Seller Center avec Change Shipping Template dans la colonne Action -->

Après avoir enregistré, tous les produits de votre boutique TikTok utilisent ce modèle et cet entrepôt.

## En cas de problème

<b>An order says we are unable to ship it because the shipping template is not "Shipped by Seller" and the handover method is DROP_OFF.</b> Cette commande utilise TikTok Shipping, et elle peut être annulée. Liez un modèle « Shipped by Seller » à votre entrepôt, pour que vos prochaines commandes puissent être envoyées.

<b>TikTok still shows the order as not shipped.</b> Nous envoyons le numéro de suivi quand la commande est expédiée. Si TikTok n'accepte pas notre transporteur pour cette commande, le suivi peut ne pas apparaître. Vérifiez la commande dans <b>Orders</b> sur votre canal, et si elle a été expédiée, demandez-nous dans le chat de notre site, avec le numéro de commande.

<b>A TikTok order did not arrive in Orders.</b> Seules les commandes avec des produits présents dans <b>My Products</b> de votre canal remontent, et seulement quand TikTok les marque comme en attente d'expédition. Les produits que vous avez listés vous-même sur TikTok, sans les importer ou les faire correspondre depuis ici, sont ignorés.

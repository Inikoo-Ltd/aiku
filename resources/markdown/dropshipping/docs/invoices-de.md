<aside class="tldr">
Sie bezahlen die Bestellung, nicht die Rechnung: Die Rechnung wird erstellt, sobald das Lager Ihre Bestellung abschließt, kurz bevor sie versendet wird. Klicken Sie im linken Menü auf <b>Invoices</b>, um die Rechnungen für alle Ihre Kanäle zu sehen. Klicken Sie auf eine Referenz, um sie zu öffnen, oder laden Sie sie als PDF herunter. Um mehrere auf einmal zu erhalten, wählen Sie zwei Daten und drücken Sie <b>Export Pdf</b>.

## Wann Sie eine Rechnung erhalten

- Sie bezahlen, wenn Sie die Bestellung aufgeben, oder wenn wir die Zahlung für eine Bestellung aus Ihrem Shop einziehen. Siehe [Payment cards and options](/docs/payment-cards-and-options).
- Die Rechnung wird erstellt, wenn die Bestellung versendet wird (Status <b>Finalized</b>). Eine bezahlte Bestellung, die sich noch im Lager befindet, hat noch keine Rechnung.
- Die Rechnung gilt für das, was wir tatsächlich versenden. Konnten manche Produkte nicht versendet werden, stehen sie nicht auf der Rechnung, und das dafür bezahlte Geld geht zurück auf Ihr Guthaben.
- Wird eine Bestellung erstattet, erscheint die Rückerstattung in der Liste <b>Invoices</b> als eigene Zeile, betitelt mit <b>Credit Note</b>.

Auf der Rechnung selbst ist nichts zu bezahlen. Sie zeigt, was Sie bereits bezahlt haben.

## Ihre Rechnungen finden

1. Klicken Sie im linken Menü auf <b>Invoices</b>.
2. Die Liste zeigt <b>Reference</b>, <b>channel</b>, <b>Date</b> und <b>total</b>. Das Symbol am Anfang jeder Zeile zeigt an, ob es sich um eine Rechnung oder eine Rückerstattung handelt.
3. Nutzen Sie das Suchfeld, um eine Rechnung anhand ihrer Referenz zu finden.
4. Klicken Sie auf eine Referenz, um die Rechnung zu öffnen.

Sie können die Rechnung auch direkt aus der Bestellung öffnen: Öffnen Sie die Bestellung und sehen Sie sich das Feld <b>Invoices</b> an. Das PDF-Symbol dort (<b>Download invoice</b>) lädt sie herunter.

## Eine Rechnung öffnen und herunterladen

Klicken Sie auf die Referenz, um die Rechnung zu öffnen. Sie sehen:

- Ihre Angaben: Name, Firma, Telefon, Steuernummer und Adresse.
- Das Datum, an dem die Rechnung erstellt wurde, und wie viel bezahlt wurde.
- Eine Zusammenfassung: Produkte, Gebühren, Verpackung, Versand, Versicherung und Steuer.
- Tabs mit den Positionen, den <b>Payments</b>, den <b>Refunds</b> und der <b>History</b>.

Drücken Sie oben auf <b>PDF</b>, um die Rechnung herunterzuladen.

## Mehrere Rechnungen auf einmal herunterladen

1. Wählen Sie oben auf der Seite <b>Invoices</b> ein Start- und ein Enddatum.
2. Die Liste zeigt die Rechnungen zwischen diesen Daten.
3. Drücken Sie <b>Export Pdf</b>. Ein einziges PDF mit all diesen Rechnungen und Rückerstattungen öffnet sich, nacheinander. Das ist nützlich für Ihren Steuerberater.

## Ihre Angaben auf Rechnungen ändern

Ihr Firmenname, Ihre Adresse oder Ihre Steuernummer stammen aus Ihrem Konto. Der Hauptnutzer kann sie unter <b>Manage Account</b> → <b>Account Settings</b> ändern. Rechnungen, die nach der Änderung erstellt werden, verwenden die neuen Angaben. Für eine bereits erstellte Rechnung kontaktieren Sie uns im Chat auf unserer Website.

## Wenn etwas schiefgeht

**eBay, TikTok or Amazon asks me for an invoice or proof of supply.** Unsere Rechnungen sind an Sie ausgestellt, nicht an Ihren Käufer. Sie erscheinen unter <b>Invoices</b>, sobald die Bestellung versendet ist. Laden Sie das PDF herunter und legen Sie es dem Marktplatz als Nachweis der Lieferung vor. Sie stellen Ihrem Käufer selbst eine Rechnung aus: Wir stellen Ihrem Käufer nie eine Rechnung aus.

**The marketplace asks for proof that I may resell your products.** Fragen Sie uns im Chat auf unserer Website nach einer Vollmacht.

**I cannot find the invoice for an order.** Prüfen Sie den Bestellstatus. Ist er noch nicht <b>Finalized</b> oder <b>Dispatched</b>, gibt es noch keine Rechnung. Ist er es, kontaktieren Sie uns im Chat auf unserer Website mit der Bestellreferenz.

**"No invoices found for the given date range" when exporting.** Zwischen den gewählten Daten gibt es keine Rechnungen. Wählen Sie einen größeren Zeitraum.

**The Export Pdf button does not work.** Wählen Sie zuerst ein Start- und ein Enddatum.

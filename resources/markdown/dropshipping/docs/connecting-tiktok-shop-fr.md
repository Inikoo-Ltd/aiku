<aside class="tldr">
Allez dans <b>Chaînes</b>, appuyez sur <b>Ajouter un canal de vente</b>, puis sur <b>Connecter</b> sur la carte TikTok. Appuyez sur <b>Auth Store</b>, approuvez notre application dans TikTok, revenez et appuyez sur <b>Suivant</b>, choisissez votre boutique et appuyez à nouveau sur <b>Suivant</b>. Avant de commencer, votre TikTok Shop a besoin d'un compte vendeur actif, d'un entrepôt par défaut avec notre adresse d'entrepôt, et d'un modèle d'expédition « Shipped by Seller » (voir les deux guides suivants). Les commandes qui utilisent TikTok Shipping peuvent être annulées.
</aside>

## Avant de commencer

Vérifiez ces points d'abord dans TikTok Shop Seller Center. Sans eux, la connexion s'arrête à mi-chemin, ou les produits et commandes échouent plus tard.

- Votre compte vendeur TikTok est actif. TikTok refuse tout import venant d'un compte inactif.
- Votre boutique a un entrepôt, et il est défini comme entrepôt par défaut. Nous envoyons votre stock à cet entrepôt. Voir [Configurer votre entrepôt TikTok Shop](/docs/tiktok-shop-warehouse).
- Votre modèle d'expédition est réglé sur « Shipped by Seller ». Nous envoyons le colis avec nos transporteurs et le suivi remonte vers TikTok. Les commandes qui utilisent TikTok Shipping peuvent être annulées. Voir [Configurer un modèle d'expédition TikTok Shop](/docs/tiktok-shop-shipping-template).

TikTok est disponible sur tous nos sites de dropshipping. Connectez-le depuis le site où vous avez votre compte dropshipping.

## Se connecter depuis votre compte dropshipping

1. Ouvrez <b>Chaînes</b> dans le menu. La page <b>Sales Channels</b> liste les canaux que vous avez déjà.
2. Appuyez sur <b>Ajouter un canal de vente</b>. La page <b>Create Channels</b> s'ouvre.
3. Sur la carte <b>Tiktok</b>, appuyez sur <b>Connecter</b>. Une fenêtre appelée <b>Connect to Tiktok channel</b> s'ouvre.
4. Lisez l'encadré <b>Warning!</b>. La connexion TikTok est encore en bêta. Utilisez « Shipped by Seller » pour vos commandes : les commandes qui utilisent TikTok Shipping peuvent être annulées.
5. Appuyez sur <b>Auth Store</b>. TikTok s'ouvre dans un nouvel onglet du navigateur.

## Approuver notre application dans TikTok

Dans le nouvel onglet, connectez-vous à TikTok Shop Seller Center si on vous le demande.

1. Choisissez votre type de vendeur et le pays de votre TikTok Shop, puis continuez.
2. Confirmez l'installation de notre application.
3. Lisez les permissions, cochez la case pour les accepter, et appuyez sur « Authorise ».
4. TikTok vous envoie vers une page qui indique <b>Congrats!</b>. Vous pouvez fermer cet onglet et revenir à l'onglet de votre compte dropshipping.

<!-- screenshot: la page d'autorisation TikTok avec la case des permissions cochée -->

## Choisir votre boutique

1. De retour dans la fenêtre <b>Connect to Tiktok channel</b>, appuyez sur <b>Suivant</b>.
2. Sous <b>Select your shop:</b>, choisissez la boutique TikTok depuis laquelle vous voulez vendre, et appuyez sur <b>Suivant</b>.
3. Vous voyez <b>Connected!</b>. Appuyez sur <b>OK</b>.

<b>Connected!</b> s'affiche même quand votre boutique TikTok n'a pas d'entrepôt par défaut. Ouvrez le canal pour vérifier : s'il affiche <b>Your TikTok shop has no warehouse yet</b>, la connexion n'est pas terminée. Voir [Configurer votre entrepôt TikTok Shop](/docs/tiktok-shop-warehouse).

Votre boutique TikTok apparaît maintenant dans <b>Chaînes</b> et dans le menu. Cliquez sur son nom pour ouvrir le canal. De là, vous ajoutez des produits à <b>My Products</b> et les importez vers TikTok, et vos commandes TikTok arrivent dans <b>Orders</b>.

Si vous fermez la fenêtre avant d'avoir choisi une boutique, ouvrez le canal depuis <b>Chaînes</b>. Vous voyez le message <b>Your registration is not complete yet, you can continue choose your shop here</b>. Choisissez votre boutique et appuyez sur <b>Save</b>.

## Si vous avez commencé depuis TikTok

Vous pouvez aussi installer notre application depuis TikTok Shop. Après l'avoir approuvée, la page <b>Congrats!</b> vous demande de choisir l'un de nos sites. Appuyez sur <b>Register</b> si vous êtes nouveau, ou sur <b>Login</b> si vous avez déjà un compte sur ce site. La boutique TikTok est ajoutée à ce compte comme canal. Ouvrez-le depuis <b>Chaînes</b> et choisissez votre boutique comme ci-dessus.

Choisissez le site qui correspond à l'endroit d'où vous voulez que vos commandes partent. Le canal appartient au compte avec lequel vous vous connectez.

## Comment fonctionnent les commandes et le stock

- Nous envoyons le niveau de stock de chaque produit importé vers votre entrepôt TikTok par défaut, et le tenons à jour.
- Quand une commande TikTok est payée et en attente d'expédition, elle arrive dans <b>Orders</b> sur votre canal. Seuls les produits présents dans <b>My Products</b> de votre canal remontent. Une commande sans aucun de nos produits est ignorée.
- La commande est payée depuis votre solde, ou depuis votre carte enregistrée si le solde ne suffit pas. Si nous ne pouvons pas prélever le paiement, la commande attend et nous vous envoyons un e-mail.
- Si l'acheteur annule sur TikTok, la commande est aussi annulée chez nous, tant qu'elle n'a pas été envoyée.
- Si votre acheteur veut retourner quelque chose, il ne doit rien renvoyer avant que cela ait été convenu avec nous dans le chat de notre site. Les remboursements vont sur votre solde.
- Quand nous expédions une commande qui utilise « Shipped by Seller », nous envoyons le numéro de suivi à TikTok pour vous. Vous n'avez pas besoin de la marquer expédiée sur TikTok vous-même.

## Factures et preuve d'approvisionnement

Nos factures sont établies à votre nom, pas à celui de votre acheteur. Vous les trouvez sous <b>Invoices</b> une fois la commande expédiée. Si TikTok demande une preuve d'approvisionnement, vous pouvez leur montrer ces factures.

Vous facturez vous-même votre acheteur. Nous ne facturons jamais votre acheteur.

Si TikTok demande une preuve que vous êtes autorisé à revendre nos produits, demandez-nous dans le chat de notre site une lettre d'autorisation.

## Reconnecter un canal que vous avez fermé

Si vous avez fermé votre canal TikTok et reconnectez le même compte TikTok avec <b>Auth Store</b>, vous récupérez l'ancien canal avec ses produits. Vous n'obtenez pas de second canal.

## En cas de problème

<b>No authenticated TikTok channel found.</b> Vous avez appuyé sur <b>Suivant</b> avant que TikTok ait terminé. Appuyez à nouveau sur <b>Auth Store</b>, terminez toutes les étapes sur TikTok, puis appuyez sur <b>Suivant</b>. Remarque : la page <b>Congrats!</b> peut s'afficher même quand TikTok n'a pas terminé, donc si vous voyez ce message, refaites les étapes sur TikTok.

<b>Your TikTok channel is not authorized yet. Please contact support.</b> TikTok ne nous a donné aucune boutique pour votre compte. Vérifiez dans Seller Center que votre boutique est configurée et active, puis réessayez. Si cela échoue encore, demandez-nous dans le chat de notre site.

<b>Please select at least one shop.</b> Choisissez une boutique dans la liste avant d'appuyer sur <b>Suivant</b>.

<b>Your TikTok shop has no warehouse yet.</b> Ajoutez un entrepôt dans TikTok Seller Center et définissez-le par défaut. Puis ouvrez le canal, choisissez votre boutique et appuyez à nouveau sur <b>Save</b>.

<b>Your channel is not connected yet to the platform.</b> La connexion ne s'est pas terminée. Appuyez sur <b>Delete</b> sous <b>Or delete the channel and try again</b>, puis reconnectez-vous depuis <b>Add Sales Channel</b>.

Messages que vous pouvez voir en important des produits vers TikTok. Ce sont des règles TikTok, et seul TikTok peut les changer :

- <b>requires an active seller account</b> : votre compte vendeur TikTok est inactif. Activez-le dans Seller Center, puis importez à nouveau.
- <b>Shop probation period</b> ou <b>Shop probation tier</b> : les nouvelles boutiques TikTok ne peuvent lister qu'un nombre limité de produits, par exemple 20, 100 ou 1000. Le message indique votre limite. Retirez des produits que vous ne vendez pas, ou attendez que TikTok lève votre limite.
- <b>category qualification for this restricted category</b> : TikTok exige que vous postuliez pour cette catégorie. Postulez dans le Qualification Center de Seller Center, puis importez à nouveau.
- <b>certifications must include every certification required by the selected category</b> : TikTok demande des documents pour ce type de produit. Ajoutez-les dans Seller Center, ou choisissez d'autres produits.
- <b>Product manufacturer is required</b> : ajoutez un fabricant dans Seller Center. Nous utilisons le premier fabricant de votre compte.
- <b>requires a return warehouse</b> : ajoutez un entrepôt de retour dans Seller Center.
- <b>at least 300 x 300 pixels</b> : l'une des images du produit est trop petite pour TikTok. Ce produit ne peut pas être importé tel quel.
- <b>product_weight</b> reçu à <b>0</b> : nous n'avons pas encore de poids pour ce produit, et TikTok en exige un. Demandez-nous dans le chat de notre site, avec le code du produit.
- <b>Incorrect price</b> : votre prix de vente est en dehors de ce que TikTok autorise. Changez votre prix de vente pour le produit dans <b>My Products</b> et importez à nouveau.
- <b>No warehouse matches 0</b>, <b>Nonexistent warehouse ID(s): 0</b> ou <b>the warehouse does not belong to this shop</b> : nous n'avons pas d'entrepôt TikTok utilisable pour votre canal. Voir [Configurer votre entrepôt TikTok Shop](/docs/tiktok-shop-warehouse).

Si une commande n'a pas été expédiée parce qu'elle utilise TikTok Shipping, lisez [Configurer un modèle d'expédition TikTok Shop](/docs/tiktok-shop-shipping-template).

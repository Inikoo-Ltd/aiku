<aside class="tldr">
Go to <b>Manage Account</b> in the left menu, then <b>Users</b>, and press <b>User</b> to add someone. Each person gets their own username and password but works in the same account: the same channels, orders, balance and invoices. Only the main user, the one who registered the account, can add, change or remove users.
</aside>

## Who can do what

- The person who registered the account is the main user.
- Only the main user can open <b>Account Settings</b> and <b>Users</b>, so only the main user can add, change or remove users.
- Every user works with the same channels, products, orders, payments, balance and invoices. There are no separate permissions for these, so only add people you trust with your money and orders.
- An account can have about 20 users.

## Add a user

1. In the left menu, press <b>Manage Account</b>.
2. At the top, press <b>Users</b>. You see the list of people who can log in to your account.
3. Press the <b>User</b> button (with the plus sign). The <b>Create User</b> page opens.
4. Fill in:
   - <b>Contact name</b>: the person's name.
   - <b>Email</b> (required): their own email. It cannot be an email that already has a login on this website.
   - <b>Username</b> (required): at least 4 characters. Use only letters, numbers, dots (.), dashes (-) and underscores (_). No spaces.
   - <b>Password</b> (required): at least 8 characters.
5. Press <b>Save</b>.

Give the new user their username and password yourself, and the address of the login page. They can log in with their username or their email. They can change the password later with <b>Forgot password?</b> on the login page.

## Change a user

1. Go to <b>Manage Account</b> → <b>Users</b> and click the user.
2. Press the edit (pencil) button.
3. Change <b>Contact name</b>, <b>Email</b>, <b>Username</b> or <b>Password</b>. Each field is saved on its own.

To give someone a new password, type it in <b>Password</b> and save. Tell them the new password yourself.

To stop someone logging in for a while without deleting them, switch off <b>Status</b>. The main user has no <b>Status</b> switch.

## Remove a user

1. Go to <b>Manage Account</b> → <b>Users</b>, click the user and press the edit (pencil) button.
2. Open the <b>Delete</b> section and press the delete button.

The person can no longer log in. Their past work (orders, payments) stays in the account. Do not delete the main user: that is the login you registered with.

## When something goes wrong

- You get a permission error when you open <b>Users</b> or <b>Account Settings</b>: you are not logged in as the main user. Ask the person who registered the account to do it.
- <b>Maximum number of web users reached</b>: the account already has the most users it can have. Delete a user you no longer need first.
- An error under <b>Email</b> or <b>Username</b> saying it is already taken: another login on this website uses it. Choose a different one.
- An error under <b>Username</b> about the format: remove spaces and special characters, and use at least 4 characters.
- The new user cannot log in: check the username and password you gave them. They can also go to the login page and press <b>Forgot password?</b> to set a new password by email.

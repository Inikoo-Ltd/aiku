<aside class="tldr">
Ein Set ist eine Zusammenstellung unserer Produkte, die als ein Artikel verkauft wird, zum Beispiel ein Geschenkset. Sie erstellen es im Tab <b>My Bundles</b> eines Kanals oder auf unserer Website über die Set-Schaltfläche an einem Produkt. Sie wählen die Produkte und Mengen aus, geben einen Titel, eine Beschreibung und mindestens ein Bild an und drücken <b>Create Bundle</b>. Danach erscheint es unter <b>My Bundles</b>, von wo aus Sie es wie jedes Produkt an Ihren Shop senden.
</aside>

## Wo Sets zu finden sind

Jedes Set gehört zu einem Kanal. Öffnen Sie <b>Channels</b> im Menü, klicken Sie auf den Kanal, öffnen Sie <b>My Products</b> und klicken Sie auf den Tab <b>My Bundles</b>. Alle Ihre Sets aus allen Kanälen finden Sie auch unter <b>Catalogue</b> → <b>Bundles</b>.

## Ein Set über My Bundles erstellen

1. Drücken Sie im Tab <b>My Bundles</b> auf <b>Create bundle</b>. Das Fenster <b>Create Your Bundle</b> öffnet sich bei <b>STEP 1/2</b>.
2. Geben Sie einen <b>Bundle Title</b> ein, oder drücken Sie die Sparkle-Schaltfläche (<b>Generate AI</b>), um sich einen schreiben zu lassen, sobald Sie Produkte ausgewählt haben.
3. Suchen Sie nach Produkten. Wie beim Hinzufügen von Produkten können Sie nach <b>Product</b>, <b>Department</b>, <b>Sub-department</b> oder <b>Family</b> suchen. Wählen Sie die Produkte aus und legen Sie die Menge für jedes fest.
4. Das Feld rechts addiert die Preise, während Sie fortfahren:
   - <b>Cost Price (Individual Purchase)</b>: was die Produkte kosten, wenn Sie sie einzeln kaufen.
   - <b>Bundle Price</b>: was Sie uns für das Set bezahlen. Dieser Preis ist nur niedriger als der Einzelpreis, wenn Ihre Website einen Mengenrabatt für Sets gewährt, ansonsten sind beide gleich.
   - <b>RRP</b>: die gesamte unverbindliche Preisempfehlung.
   - <b>Profit</b>: UVP minus Set-Preis, mit Prozentangabe.
5. Drücken Sie <b>Next</b>. Sie befinden sich nun bei <b>STEP 2 / 2</b>.
6. Schreiben Sie eine <b>Description</b>, oder drücken Sie <b>Generate with AI</b>. Sie können den erzeugten Text bearbeiten.
7. Fügen Sie Bilder hinzu. Ziehen Sie Dateien auf <b>Upload Media</b> (<b>Drag & drop images or click</b>), oder drücken Sie <b>Select existing media</b>, um vorhandene Fotos der Produkte im Set zu verwenden. Wählen Sie das <b>MAIN IMAGE</b> mit der runden Schaltfläche am Bild aus.
8. Optional: Drücken Sie <b>Generate Image AI</b>, um ein neues Bild zu erzeugen. Wählen Sie zuerst einige Bilder aus, haken Sie die einzubeziehenden Produktbilder an, schreiben Sie unter <b>Describe your image</b> eine Beschreibung und drücken Sie <b>Generate</b>.
9. Drücken Sie <b>Create Bundle</b>. Die Schaltfläche ist nur aktiv, wenn das Set eine Beschreibung und mindestens ein Bild hat.

Wenn Sie das Fenster vor dem Ende schließen, erscheint die Frage <b>Discard bundle?</b>. Ein Schließen verwirft das Set, und Sie müssen von vorne beginnen.

## Ein Set über unsere Website erstellen

1. Melden Sie sich an und stöbern Sie auf unserer Website.
2. Drücken Sie auf einer Produktkarte die runde Set-Schaltfläche (<b>Create bundle</b>). Auf einer Produktseite drücken Sie <b>Add to bundle</b>. Ein Panel <b>Create Your Bundle</b> öffnet sich seitlich.
3. Wählen Sie den <b>Sales Channel</b>, für den das Set bestimmt ist.
4. Stöbern Sie weiter und fügen Sie weitere Produkte hinzu. Ändern Sie Mengen oder entfernen Sie ein Produkt mit der Papierkorb-Schaltfläche.
5. Geben Sie den <b>Bundle Title</b> ein, drücken Sie <b>Next</b>, und fügen Sie dann wie oben Beschreibung und Bilder hinzu.

Die Set-Schaltfläche wird nur bei Produkten angezeigt, die vorrätig sind. Solange ein Set geöffnet ist, hindert Sie die Website am Verlassen der Seite, bis Sie fertig sind oder abbrechen.

## Das Set an Ihren Shop senden

Das Set befindet sich jetzt unter <b>My Bundles</b>. Es funktioniert wie eine Zeile auf <b>My Products</b>: Drücken Sie <b>Create new product</b>, um es in Ihrem Shop anzulegen, oder ordnen Sie es einem bereits vorhandenen Listing zu. Siehe [Using My Products](/docs/my-products).

Ein Set hat einen eigenen Produktcode, der als SKU an Ihren Shop gesendet wird.

## Ein Set ändern oder entfernen

- <b>Edit Bundle</b> (Stift-Schaltfläche): Titel, Beschreibung, Bilder, Produkte und UVP ändern. <b>Save</b> behält die Änderungen nur bei uns. Wenn das Set mit Ihrem Shop verknüpft ist, sendet <b>Save & Sync</b> Titel und Beschreibung außerdem an Ihren Shop (<b>Bundle saved and synchronised with ...</b>). Nach einem einfachen <b>Save</b> zeigt ein Warnsymbol in der Zeile <b>Saved changes have not been pushed to ... yet</b> an.
- <b>Unlink Bundle</b> (rote Schaltfläche zum Trennen): stoppt das Set. Wir markieren es als eingestellt, sodass es nicht mehr bestellt werden kann, und die Verknüpfung mit Ihrem Shop wird entfernt. Es wird nicht vorher nachgefragt, und dies kann nicht rückgängig gemacht werden: Um dieselbe Zusammenstellung erneut zu verkaufen, erstellen Sie ein neues Set. Das Listing bleibt in Ihrem Shop bestehen, löschen Sie es dort selbst.

## Set-Daten herunterladen

Die <b>CSV</b>-Exporte unter <b>My Products</b> lassen Sets aus, sofern Sie nicht unter <b>⋮</b> die Option <b>Include bundles</b> anhaken. Siehe [Exporting product data and images](/docs/exporting-product-data).

## Wenn etwas schiefgeht

- **"The OpenAI service is currently unreachable, please try again later."** Der KI-Schreibassistent hat nicht geantwortet. Versuchen Sie es später erneut oder schreiben Sie den Text selbst.
- **"You have reached the limit of 3 attempts."** Jede KI-Schaltfläche (Titel, Beschreibung und Bild) kann innerhalb von 5 Minuten 3-mal genutzt werden. Warten Sie 5 Minuten und versuchen Sie es erneut.
- **Die Schaltfläche Create Bundle bleibt grau.** Fügen Sie eine Beschreibung und mindestens ein Bild hinzu.
- **"Failed to create bundle" / "Failed to submit the data, please try again".** Prüfen Sie, ob der Titel ausgefüllt ist und jedes Produkt eine Menge von mindestens 1 hat, und versuchen Sie es dann erneut. Schlägt es weiterhin fehl, kontaktieren Sie uns im Chat auf unserer Website.
- **Das Set wird nicht in meinen Shop hochgeladen.** Lesen Sie die rote Meldung in seiner Zeile. Es ist die Antwort Ihrer Plattform, genauso wie bei Produkten. Siehe die Liste in [Using My Products](/docs/my-products).

<aside class="tldr">
Gehen Sie im linken Menü zu <b>Manage Account</b>, dann <b>Users</b>, und drücken Sie <b>User</b>, um jemanden hinzuzufügen. Jede Person erhält einen eigenen Benutzernamen und ein eigenes Passwort, arbeitet aber im selben Konto: dieselben Kanäle, Bestellungen, Guthaben und Rechnungen. Nur der Hauptbenutzer, derjenige, der das Konto registriert hat, kann Benutzer hinzufügen, ändern oder entfernen.
</aside>

## Wer was tun kann

- Die Person, die das Konto registriert hat, ist der Hauptbenutzer.
- Nur der Hauptbenutzer kann <b>Account Settings</b> und <b>Users</b> öffnen, daher kann nur der Hauptbenutzer Benutzer hinzufügen, ändern oder entfernen.
- Jeder Benutzer arbeitet mit denselben Kanälen, Produkten, Bestellungen, Zahlungen, Guthaben und Rechnungen. Es gibt dafür keine separaten Berechtigungen, fügen Sie also nur Personen hinzu, denen Sie mit Ihrem Geld und Ihren Bestellungen vertrauen.
- Ein Konto kann etwa 20 Benutzer haben.

## Einen Benutzer hinzufügen

1. Drücken Sie im linken Menü auf <b>Manage Account</b>.
2. Drücken Sie oben auf <b>Users</b>. Sie sehen die Liste der Personen, die sich in Ihrem Konto anmelden können.
3. Drücken Sie die Schaltfläche <b>User</b> (mit dem Plus-Zeichen). Die Seite <b>Create User</b> öffnet sich.
4. Füllen Sie aus:
   - <b>Contact name</b>: der Name der Person.
   - <b>Email</b> (erforderlich): ihre eigene E-Mail-Adresse. Es darf keine E-Mail-Adresse sein, die auf dieser Website bereits einen Zugang hat.
   - <b>Username</b> (erforderlich): mindestens 4 Zeichen. Verwenden Sie nur Buchstaben, Zahlen, Punkte (.), Bindestriche (-) und Unterstriche (_). Keine Leerzeichen.
   - <b>Password</b> (erforderlich): mindestens 8 Zeichen.
5. Drücken Sie <b>Save</b>.

Geben Sie dem neuen Benutzer selbst seinen Benutzernamen, sein Passwort und die Adresse der Login-Seite. Er kann sich mit seinem Benutzernamen oder seiner E-Mail-Adresse anmelden. Das Passwort kann später mit <b>Forgot password?</b> auf der Login-Seite geändert werden.

## Einen Benutzer ändern

1. Gehen Sie zu <b>Manage Account</b> → <b>Users</b> und klicken Sie auf den Benutzer.
2. Drücken Sie die Bearbeiten-Schaltfläche (Stift).
3. Ändern Sie <b>Contact name</b>, <b>Email</b>, <b>Username</b> oder <b>Password</b>. Jedes Feld wird für sich gespeichert.

Um jemandem ein neues Passwort zu geben, tippen Sie es in <b>Password</b> ein und speichern Sie. Teilen Sie der Person das neue Passwort selbst mit.

Um jemanden vorübergehend an der Anmeldung zu hindern, ohne ihn zu löschen, schalten Sie <b>Status</b> aus. Der Hauptbenutzer hat keinen <b>Status</b>-Schalter.

## Einen Benutzer entfernen

1. Gehen Sie zu <b>Manage Account</b> → <b>Users</b>, klicken Sie auf den Benutzer und drücken Sie die Bearbeiten-Schaltfläche (Stift).
2. Öffnen Sie den Bereich <b>Delete</b> und drücken Sie die Löschen-Schaltfläche.

Die Person kann sich nicht mehr anmelden. Ihre bisherige Arbeit (Bestellungen, Zahlungen) bleibt im Konto erhalten. Löschen Sie nicht den Hauptbenutzer: Das ist der Zugang, mit dem Sie sich registriert haben.

## Wenn etwas schiefgeht

- Sie erhalten einen Berechtigungsfehler, wenn Sie <b>Users</b> oder <b>Account Settings</b> öffnen: Sie sind nicht als Hauptbenutzer angemeldet. Bitten Sie die Person, die das Konto registriert hat, dies zu tun.
- <b>Maximum number of web users reached</b>: Das Konto hat bereits die maximale Anzahl an Benutzern erreicht. Löschen Sie zuerst einen nicht mehr benötigten Benutzer.
- Ein Fehler unter <b>Email</b> oder <b>Username</b>, der besagt, dass dies bereits vergeben ist: Ein anderer Zugang auf dieser Website verwendet ihn bereits. Wählen Sie einen anderen.
- Ein Fehler unter <b>Username</b> zum Format: Entfernen Sie Leerzeichen und Sonderzeichen, und verwenden Sie mindestens 4 Zeichen.
- Der neue Benutzer kann sich nicht anmelden: Prüfen Sie den Benutzernamen und das Passwort, die Sie ihm gegeben haben. Er kann auch auf der Login-Seite <b>Forgot password?</b> drücken, um sich per E-Mail ein neues Passwort zu setzen.

<aside class="tldr">
Gehen Sie zu <b>Channels</b>, drücken Sie <b>Add Sales Channel</b>, dann <b>Connect</b> auf der Wix-Karte. Wix öffnet sich in einem neuen Tab: Wählen Sie Ihre Website und installieren Sie unsere App. Sobald die Installation abgeschlossen ist, schickt Wix Sie zurück zu Ihrem neuen Kanal in Ihrem Dropshipping-Konto. Ihre Wix-Website muss <b>Wix Stores</b> installiert haben, sonst bleibt der Kanal nicht bereit.
</aside>

## Bevor Sie beginnen

- Sie benötigen eine Wix-Website mit installiertem <b>Wix Stores</b>. Wir fügen Produkte zu Wix Stores hinzu und lesen Ihre Bestellungen von dort. Sie können unsere App auch auf einer Website ohne Wix Stores installieren, aber der Kanal bleibt nicht bereit, bis Sie es hinzufügen.
- Melden Sie sich im selben Browser bei Wix an, mit dem Konto, dem die Website gehört.
- Wix ist auf allen unseren Dropshipping-Websites verfügbar. Verbinden Sie es von der Website aus, auf der Sie Ihr Dropshipping-Konto haben.

## Ihre Wix-Website verbinden

1. Öffnen Sie <b>Channels</b> im Menü. Auf der Seite <b>Sales Channels</b> werden Ihre bereits vorhandenen Kanäle aufgelistet.
2. Drücken Sie <b>Add Sales Channel</b>. Die Seite <b>Create Channels</b> öffnet sich.
3. Suchen Sie die <b>Wix</b>-Karte und drücken Sie <b>Connect</b>. Wix öffnet sich in einem neuen Tab.
4. Falls Wix danach fragt, melden Sie sich an. Wählen Sie die Website, die Sie verbinden möchten, und installieren Sie die App. Wix zeigt die von der App benötigten Berechtigungen an; akzeptieren Sie sie, um fortzufahren.
5. Sobald die Installation abgeschlossen ist, schickt Wix Sie zurück zu Ihrem Dropshipping-Konto und öffnet das Dashboard Ihres neuen Kanals.

<!-- screenshot: die Wix-Seite, auf der Sie die Website auswählen und die App installieren -->

Schließen Sie die Installation innerhalb von zwei Stunden nach dem Drücken von <b>Connect</b> ab. Danach läuft der Link ab, und Sie müssen erneut <b>Connect</b> drücken.

Der Kanal erhält den Namen Ihrer Wix-Website. Sie können ihn später unter <b>Manage Sales Channel</b>, <b>Store name</b> ändern.

## Prüfen, ob der Kanal bereit ist

Auf dem Kanal-Dashboard sehen Sie neben dem Kanalnamen drei kleine Häkchen:

- <b>App installed</b>: Wir können Ihre Wix-Website erreichen.
- <b>Exist in platform</b>: Die Website existiert bei Wix.
- <b>Platform status</b>: Die Website ist bereit, unsere Produkte zu verkaufen.

Halten Sie die Maus über ein Häkchen, um seinen Namen zu sehen. Drei grüne Häkchen bedeuten, dass Sie bereit sind, Produkte hinzuzufügen. Fahren Sie mit der Anleitung zum Hochladen von Produkten zu Wix fort.

Können wir Ihre Wix-Website überhaupt nicht erreichen, werden die Häkchen nicht angezeigt. Sie sehen stattdessen eine rote Meldung, wie unten erklärt.

<!-- screenshot: das Kanal-Dashboard mit dem Wix-Logo, dem Kanalnamen und drei grünen Häkchen -->

Das Dashboard zeigt außerdem Felder für <b>Orders</b> und <b>Products</b>. Drücken Sie <b>View all</b> auf einem Feld, um die jeweilige Liste zu öffnen.

## Mehr als eine Wix-Website verbinden

Jede Wix-Website ist ein eigener Kanal. Um eine weitere Website hinzuzufügen, gehen Sie zurück zu <b>Channels</b>, drücken Sie erneut <b>Add Sales Channel</b> und <b>Connect</b> auf der Wix-Karte, und wählen Sie dann die andere Website in Wix.

## Wenn etwas schiefgeht

<b>The page says: Wix Stores is not installed on this site. Add the Wix Stores app to the site, then reconnect the channel.</b>
Ihre Website hat keinen Online-Shop. Fügen Sie in Wix die App Wix Stores zur Website hinzu. Öffnen Sie dann den Kanal in Ihrem Dropshipping-Konto und drücken Sie <b>Try to reconnect</b>.

<b>The page says: Your channel is not connected yet to the platform.</b>
Wir konnten Ihre Wix-Website nicht erreichen. Dies passiert, wenn die App von der Website entfernt wurde oder die Installation nicht abgeschlossen wurde. Drücken Sie <b>Try to reconnect</b>. Der Wix-Installer öffnet sich erneut: Installieren Sie die App auf derselben Website.

<b>The Wix tab shows a short message instead of sending you back</b>
- <b>The Wix installation was not completed</b>: Die Installation wurde vor dem Ende abgebrochen. Drücken Sie erneut <b>Connect</b> und schließen Sie alle Schritte in Wix ab.
- Eine Fehlerseite: Der Link ist mehr als zwei Stunden alt. Gehen Sie zurück zu <b>Create Channels</b> und drücken Sie erneut <b>Connect</b>.

<b>You want to start again</b>
Drücken Sie unter der Warnung im Kanal-Dashboard auf <b>Delete</b> neben <b>Or delete the channel and try again</b>. Verbinden Sie die Website dann erneut über <b>Create Channels</b>.

Haben Sie unsere App absichtlich von Ihrer Wix-Website entfernt, funktioniert der Kanal nicht mehr: Wir können weder Lagerbestand senden noch Bestellungen empfangen. Installieren Sie die App mit <b>Try to reconnect</b> erneut, um den Kanal wieder zu nutzen.

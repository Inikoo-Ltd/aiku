# Where Is the Tracking Number for My Order?

Welcome to AW Dropship!

This guide shows you where to find the tracking number for your order.

Here is the tutorial you can follow:

1. Log in to your dashboard and go to the Orders section.

   _(Screenshot on the original page: the Orders section of the dashboard)_

2. In the order list, you will see a Reference Code for each order.

   _(Screenshot on the original page: the order list with the Reference Code column)_

3. This is the AWD order reference number, not the tracking number. Please click the AWD order reference number in the order list and you will find the tracking number listed under 'shipments' in the delivery notes section.

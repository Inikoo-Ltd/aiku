# Reviewing Your Orders

Welcome to AW Dropship!

The order review feature allows you to view and check the details of orders that have been placed through your connected store. This helps you ensure that all order information is correct before the order is processed.

## Tutorial

After logging in to your dashboard, go to the Orders section. On this page, you will see a list of all orders created through your store.

_(Screenshot on the original page: the Orders list with order reference, status and date created)_

Each order in the list shows basic information such as the order reference, order status, and date created. To review an order, click on the Code Reference displayed in the order list.

_(Screenshot on the original page: the order list with the Code Reference highlighted)_

After clicking the code reference, you will be taken to the order review page. Here you can see the full order details, including the products included in the order.

_(Screenshot on the original page: the order review page with full order details)_

On the order review page, you can check product quantities, pricing, delivery details, and the current order status to make sure all information is correct.

If you have any questions or experience any issues while reviewing your orders, please check the related help articles or contact our support team for further assistance.

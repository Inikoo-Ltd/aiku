# User Management Guide

User Management allows you to add team members to your AW Dropship account, so they can help manage different areas of your workflow.

## Tutorial 1: How to Add a New User

### 1. Register and Log In

Once you register, log in to your AW Dropship account. After logging in, you will be taken to the main website dashboard.

### 2. Open Your Account (My Store)

On the top-right menu, click **My Store** to access your account area.

_(Screenshot on the original page: the My Store link in the top-right menu)_

### 3. Go to Manage Account

From the left-hand menu inside your account dashboard, scroll down and click **Manage Account**.

_(Screenshot on the original page: Manage Account in the left-hand menu)_

### 4. Open the Users Tab

In the Account Management page, click **Users** to view the list of users currently linked to your account.

_(Screenshot on the original page: the Users tab on the Account Management page)_

### 5. Click "+ user"

On the Users page, click the **+ user** button to create a new user.

_(Screenshot on the original page: the + user button on the Users page)_

### 6. Fill in User Details and Save

On the Create User screen, complete the required fields (such as contact name, email, username, and password). Once ready, click **Save** to add the user.

_(Screenshot on the original page: the Create User form)_

### 7. Confirm the User Has Been Added

After saving, you will be redirected back to the Users list. Make sure the new user appears in the list to confirm it was added successfully.

_(Screenshot on the original page: the Users list showing the new user)_

## Tutorial 2: How to Delete a User (Optional)

### 1. Open the User and Edit

From the Users list, click the user you want to remove, then click the edit (pencil) icon.

### 2. Delete the User

In edit mode, go to **Delete** and click the **Delete** button to remove the user from your account.

_(Screenshot on the original page: the Delete button in user edit mode)_

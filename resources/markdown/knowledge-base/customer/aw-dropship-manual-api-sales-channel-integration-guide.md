# Manual/API Sales Channel Integration Guide

Welcome to AW Dropship! This guide shows you how to create a Manual / API Sales Channel in your AW Dropship account.

The Manual / API option is for users who want to connect AW Dropship to their own website, custom platform or application, instead of a pre-built integration such as Shopify or WooCommerce.

## Getting Started

After you register and log in, you will see the AW Dropship dashboard. Here you can manage your sales channels, orders, products and clients.

_(Screenshot on the original page: an overview of the AW Dropship dashboard)_

## Create Your Channel

From the dashboard menu:

1. Click Channels
2. Select Add Sales Channel

_(Screenshot on the original page: the list of sales channel options)_

In the list of sales channels:

1. Find Manual Web / API
2. Click Create

_(Screenshot on the original page: the Manual Web / API option with the Create button)_

## Channel Setup

After you click Create, a pop-up window will appear. In this window:

1. Enter your Store Name (for example, your website or platform name)
2. Click Create

_(Screenshot on the original page: the Store Name pop-up)_

## After Creation

After you create the channel, you will be redirected to your Manual Store Order Management page. From there, you can:

- Manage orders
- View and manage clients
- View and manage products

_(Screenshot on the original page: the Manual Store Order Management dashboard)_

# Exporting Full Product Details, Basic Product Details & Product Prices

Welcome to AW Dropship!

This tutorial explains how to export your product inventory to a CSV file using the My Products menu.

Once you register, you will see this dashboard on your screen.

_(Screenshot on the original page: the AW Dropship dashboard)_

You can go to the floating menu on the side and then click My Products.

_(Screenshot on the original page: the floating side menu with the My Products option)_

From this interface, you can click the **CSV button** to export.

_(Screenshot on the original page: the My Products interface with the CSV button)_

Next you will be redirected to the download page. Once the download dialog appears, select Save.

_(Screenshot on the original page: the browser download dialog with the Save option)_

Once it successfully exports, feel free to open the file on your computer to review or make changes.

The sheet includes the following information:

- Status
- Product code
- Product user reference
- Family
- Barcode
- CPNP number
- Price
- Units per outer
- Unit label
- Unit price
- Unit Name
- Unit RRP
- Unit net weight
- Package weight (shipping)
- Unit dimensions
- Materials/Ingredients
- Webpage description (html)
- Webpage description (plain text)
- Country of origin
- Tariff code
- Duty rate
- HTS US
- Stock
- Images
- Data updated
- Stock updated
- Price updated
- Images updated
- Available Quantity
